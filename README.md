# Model Comparison using Iris Dataset

## Overview

This project focuses on comparing the performance of three machine learning models on the Iris dataset. The goal is to understand how different algorithms perform on the same data and determine which model gives the best accuracy.

## Objective

* Train multiple machine learning models
* Evaluate their performance
* Compare accuracy results
* Identify the best-performing model

## Models Used

* Logistic Regression
* K-Nearest Neighbors (KNN)
* Decision Tree

## Dataset

The Iris dataset is a simple and commonly used dataset for classification tasks. It contains:

* Input features: sepal length, sepal width, petal length, petal width
* Output labels: different types of iris flowers

## Approach

1. Load the dataset using sklearn library
2. Separate input features (X) and output labels (y)
3. Split the dataset into training and testing sets
4. Train all three models using the training data
5. Make predictions on the testing data
6. Calculate accuracy for each model
7. Compare the results
